# Projects

> **Format of this doc:** For every
> project you get four blocks in the same order — **Deep Dive** (the technical substance, so you can
> go three questions deep), **STAR** (the structured version), **Script** (what you actually say out
> loud, timed), and **Follow-ups** (the questions that will come next, with answers). **Tone note:**
> Every one of these is written the way it actually happened — you _noticed_ the problem, you
> _chose_ the approach, you _drove_ it to adoption. Nothing here reads as "I was handed a ticket,"
> because that isn't what happened.
